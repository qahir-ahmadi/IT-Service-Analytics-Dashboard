# Resume Bullets

**IT Service Analytics Dashboard | Python, PostgreSQL, SQL, Pandas, Power BI**

- Built an IT service analytics solution using 5,000 synthetic support tickets to measure ticket volume, backlog, SLA compliance, resolution time, and customer satisfaction.
- Cleaned and transformed support data with Python and Pandas and designed SQL queries to analyze service trends, technician performance, and recurring issue categories.
- Designed a Power BI dashboard with operational KPIs and drill-down views to identify support bottlenecks and service-level performance.
